🧩 Header·Branch 관경

Q = A×V  |  Header n = Branch n ~ Branch(마지막) 누적유량  |  D = √(4A/π)×1000
📌 사용 방법
① 분기(Branch) 개수를 고르고 각 Branch의 유량을 입력하세요 (LPM·M³/HR·Kcal/h·RT 중 하나만 입력해도 자동 환산). ② Header는 가장 먼 Branch부터 소스 방향으로 유량이 누적됩니다 (Header1 = 전체 합, 마지막 Header = 마지막 Branch만). ③ 유속(V) 기본값은 2 m/s이며, 특별한 요구사항이 없으면 이 값을 기준으로 사용하세요.
Branch 개수
Branch별 유량 · 유속 입력
LPM · M³/HR · Kcal/h · RT 중 하나만 입력해도 나머지가 자동 환산됩니다. (LPM = Kcal/h ÷ 300, RT = Kcal/h ÷ 3024, 냉각수 ΔT 5℃ 기준 개산식)
🌬️ Header 공통 유속 (V, m/s)
회색 숫자는 기본값(2 m/s)입니다. 특별한 요구사항이 없으면 이 기준을 사용하고, 필요 시 직접 입력해 변경할 수 있습니다.
